# Jarvis Alerts — аддон для Meteor Client (Minecraft 1.21.11, Fabric)

Модуль **jarvis-alerts** в категории **Jarvis**. Озвучивает события только у ДРУГИХ игроков:

| Событие | Файл в `src/main/resources/assets/jarvis/sounds/` |
|---|---|
| Сработал тотем | `totem_pop.wav` |
| Сломался шлем | `helmet_break.wav` |
| Сломался нагрудник | `chestplate_break.wav` |
| Сломались поножи | `leggings_break.wav` |
| Сломались ботинки | `boots_break.wav` |
| Мало HP (один раз, пока игрок не восстановится) | `low_hp.wav` |

Все звуки вшиваются внутрь jar, ничего копировать в папки не нужно: отправляешь другу один файл `.jar`.

## Если Gradle ругается на версии
Версии в `gradle/libs.versions.toml` (yarn-mappings, fabric-loader, loom) подобраны по памяти.
Актуальные значения для 1.21.11 смотри на https://fabricmc.net/develop и подставь их.

## Настройки модуля
- включение каждого события отдельно;
- порог HP (в очках здоровья, 2 = 1 сердце);
- громкость, пауза между повторами одного звука;
- игнорировать друзей.
